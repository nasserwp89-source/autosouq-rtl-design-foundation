# Autosouq Rtl Design Foundation

أرفقت لك ثلاثة ملفات أساسية لمشروع AutoSouq. أريدك أن تراجعها بالكامل قبل البدء بأي تنفيذ:

Brand Book: المرجع المعتمد للهوية البصرية، بما يشمل الألوان والخطوط والشعار والاستخدامات.

Final Lovable Context: الوثيقة التي تحتوي على رؤية المشروع ونطاق النموذج الأولي والمتطلبات التجارية والتصميمية والوظيفية.

Logo: الشعار الأصلي للعلامة التجارية.

تعليمات العمل

أريد تنفيذ المشروع على مراحل واضحة، بحيث أراجع كل مرحلة وأوافق عليها قبل الانتقال إلى المرحلة التالية.

ابدأ الآن بالمرحلة الأولى فقط:

المرحلة الأولى – Design Foundation & Layout Structure

تشمل هذه المرحلة:

إعداد نظام التصميم العام (Design System).

ضبط الألوان والخطوط وفق Brand Book.

إعداد دعم اللغة العربية واتجاه RTL بشكل صحيح.

تحديد أسلوب المكونات الأساسية (Buttons, Cards, Inputs, Navigation).

بناء Header وFooter.

إعداد الهيكل العام للصفحات (Layout Structure).

التأكد من أن التصميم Responsive على الهاتف والتابلت وسطح المكتب.

وضع الأساس البصري الذي ستُبنى عليه بقية صفحات المشروع.

قواعد مهمة

التزم بالملفات المرفقة، ولا تتخذ قرارات تخالفها.

لا تعدّل الشعار الأصلي أو تعِد رسمه.

لا تبدأ ببناء الصفحة الرئيسية أو رحلة تسجيل السيارة أو لوحة التحكم في هذه المرحلة.

لا تبدأ بأي Backend أو Database أو تكاملات خارجية.

إذا وجدت معلومة غير محسومة أو تعارضاً بين المتطلبات، اسألني قبل اتخاذ القرار.

لا تنتقل إلى المرحلة الثانية تلقائياً.

المطلوب عند الانتهاء

أريد منك:

تنفيذ المرحلة الأولى بالكامل.

عرض النتيجة بصرياً حتى أتمكن من مراجعتها.

توضيح ما تم تنفيذه.

ذكر أي افتراضات أو نقاط تحتاج إلى قراري.

عدم البدء بالمرحلة الثانية إلا بعد حصولك على موافقتي الصريحة.

مهم جداً: اعمل على المرحلة الأولى فقط، ثم توقف وانتظر ملاحظاتي وموافقتي.
